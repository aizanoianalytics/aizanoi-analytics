# Workforce Turnover Analytics

This route is generated by the original turnover analytics engine in the HR Analytics Full Set production pipeline.

## Architecture

The dashboard keeps the original analytical structure and behavior:

- eight analytical views;
- global scope, exit-type, period, region, store, department, city, gender, contract, and title filters;
- monthly and cumulative turnover, flow, exit mix, scope trends, heat maps, and title matrices;
- region/store/year comparisons;
- forecasts, confidence intervals, rolling-origin backtests, and annual backtests;
- early-tenure analysis and exit drill-down;
- regrettable turnover, survival analysis, entity risk, and synthetic profile risk detail;
- browser-local reason classification with CSV and JSON import/export.

`production-pipeline/generate_turnover_dashboard.py` reads the integrated analytical workbook, injects its compact payload into the original offline HTML template, and emits the complete self-contained dashboard. The published page has no runtime backend or network data dependency.

## Data safety

The integrated workbook is generated by the original production pipeline from 27 deterministic fictional source workbooks. It is not an anonymized, masked, sampled, or transformed employer workbook.

- all people use reserved numeric test identifiers;
- profile labels use `Synthetic Employee` placeholders;
- business units and locations are fictional demo labels;
- no former employer workbook is read by the public build;
- no real employee, contact, payroll, or employer identifier is present.

Row-level records exist because the original exit-detail and risk features require them. Every such record is synthetic.

## Rebuild the dashboard

Install Python with `numpy`, `pandas`, and `openpyxl`, then run from the repository root:

```bash
python analytics/dashboards/hr-analytics-full-set/production-pipeline/run_full_pipeline.py
```

The command reads only the 27 committed synthetic inputs and writes its outputs under `production-pipeline/dashboardlar/`. The generated turnover HTML is published unchanged at `frontend/analytics/dashboards/hr-analytics-full-set/workforce-turnover/index.html`.

## Workbook contract

The 54-sheet integrated workbook preserves every turnover input consumed by the engine: monthly analysis, exit detail, reason settings, forecasts, monthly and annual backtests, regrettable turnover, survival curves, and entity/profile risk outputs.
