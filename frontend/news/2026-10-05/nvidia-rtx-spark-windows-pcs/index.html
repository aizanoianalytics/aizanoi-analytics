Nvidia's RTX Spark Windows PCs begin shipping in October

Nvidia said the first Windows 11 laptops and compact desktops built on its RTX Spark superchip will start arriving in October, with Lenovo among the first to show designs. RTX Spark pairs a Blackwell RTX GPU with 6,144 CUDA cores and a 20-core Grace CPU over NVIDIA NVLink-C2C, offering up to one petaflop of FP4 AI compute and up to 128GB of unified memory aimed at running personal AI agents on-device. Nvidia and Microsoft are developing OS security primitives and the OpenShell runtime to support local agents.
