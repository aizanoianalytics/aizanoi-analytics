Microsoft ships Execution Containers to fence off AI agents on Windows PCs

Microsoft has released Microsoft Execution Containers (MXC), a policy-driven boundary that restricts what AI agents can read, connect to and change when they run on a Windows laptop or desktop. The company argues an agent 'cannot be its own security authority' and must run inside a limit enforced independently of it. Anthropic, OpenAI and Nvidia will use the tooling, Microsoft's Windows and devices chief Pavan Davuluri said, as part of a broader October 7 push to bring hybrid, on-device AI to Windows alongside new RTX Spark Surface hardware.
