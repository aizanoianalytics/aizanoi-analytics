Nintendo's first modchip-firmware takedown wipes 144 GitHub repositories

GitHub disabled 144 repositories after Nintendo of America sent a 6 November notice targeting firmware for Switch modchips including Picofly, SX Core, SX Lite and HWFLY. Nintendo named a single repository and GitHub removed its whole fork network, accepting that the copies infringed to the same extent. Nintendo says the code bypasses its copy protections. Installed chips keep working, but updates and new installs become harder.
