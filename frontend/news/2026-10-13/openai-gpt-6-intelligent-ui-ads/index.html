OpenAI pushes GPT-6 and an 'Intelligent UI' to every user as ad testing nears

OpenAI began rolling out GPT-6 and a new interface it calls Intelligent UI to all ChatGPT users on 7 October, citing more than 1.2 billion weekly users. Two days earlier it announced a visual advertising format, with U.S. testing to start later this month. The Financial Times reported on 8 October that OpenAI told investors annualised revenue was nearing $50bn at the end of September, below the roughly $70bn that had circulated earlier. OpenAI also expanded its Atlassian partnership so frontier models power agents across that platform.
