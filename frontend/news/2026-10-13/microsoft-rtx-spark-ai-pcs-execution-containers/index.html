Microsoft prices Nvidia-powered AI PCs and adds agent sandboxing to Windows 11

Microsoft used a San Francisco event during Tech Week to detail its Nvidia RTX Spark AI PCs. The Surface Laptop Ultra starts at $2,600, rising to $5,900 with more memory and storage, while the Surface RTX Spark Dev Box workstation starts at $6,000 and ships with VS Code, GitHub Copilot CLI, WSL and PowerShell 7. Both run a revamped Windows 11 that adds Execution Containers, a sandboxing feature for AI agents that Microsoft says will reach all Windows 11 users. Dell also detailed an RTX Spark machine.
