Anthropic launches Enterprise Frontier Safeguards so regulated firms can run Claude with logs that never leave their own cloud

Anthropic on 1 September introduced Enterprise Frontier Safeguards, a deployment pattern that pairs Claude Fable 5.1 and Mythos 5.1 capabilities with zero-data-retention and customer-held monitoring logs. The system stores activity data in the customer's own cloud rather than in Anthropic infrastructure, and Anthropic said EFS would roll out to enterprise customers in phases from later in the autumn. The launch marks the first time Anthropic is packaging a Mythos-class restricted model behind an architecture whose safety telemetry never reaches the lab by default.
