OpenAI says reasoning-trace theft collapsed on GPT-6.2

OpenAI reports that an internal adaptive red-team evaluation recovered protected reasoning from an earlier request 54.0% of the time against GPT-6 Astra, and 0.2% of the time against GPT-6.2 Astra. The company credits adversarial training, input and output classifiers that cover streamed text and tool-call arguments, and API rules that tie a model's reasoning to the conversation that produced it. Weekly enforcement against distillation campaigns has run from thousands to tens of thousands of accounts, with the rate rising sharply this summer, OpenAI said.
