Microsoft puts a 2.3B on-device model in Edge and opens the Prompt API

Microsoft made Aion Instruct generally available on 19 November as open weights on Hugging Face and as Edge's built-in small language model, replacing Phi-4-mini. At 2.3 billion parameters the company says it is smaller than Phi and available on more devices while matching it on summarization and structured output. An origin trial now lets live websites call the Prompt API, and a developer preview adds a Decisions API that returns labels, probabilities and confidence without generating text. Edge downloads the model only when a site needs it, and users can disable on-device AI.
