Microsoft redesigns Copilot around Home, Code and Autopilot

Microsoft is introducing a new Copilot experience with Home as a combined starting point for Chat and Cowork, Code for building solutions, and Autopilot for persistent proactive work. Home and Code enter the Frontier rollout in the coming weeks, while Autopilot expands to private preview at the end of September.
