GitHub schedules Ubuntu 26.04 migration for hosted Actions runners

GitHub’s changelog records the Ubuntu 26.04 hosted-runner image as production-supported on x64 and Arm64, with the ubuntu-latest label migrating gradually from Ubuntu 24.04 between 19 October and 19 November. Projects relying on preinstalled tools are advised to test the new image or pin a version in the meantime.
