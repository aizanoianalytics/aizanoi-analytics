AWS open-sources a small decision model for agent workflows

Amazon Web Services released Strands Decider 2B, a roughly 2-billion-parameter model that scores supplied answer options instead of generating text. The company said it fine-tuned Alibaba's Qwen3.5-2B base, removed the component that predicts the next word and replaced it with a pointer over the available choices, adding a small LoRA update, and published the weights under an Apache 2.0 licence. AWS presents the model as a fast, locally runnable way to route bounded agent decisions with a calibrated confidence on each answer.
