OpenAI and Synopsys pair frontier models with chip-design tools

Synopsys and OpenAI announced a multi-year partnership to build GPT-Synopsys, a specialised model trained to operate Synopsys electronic design automation tools directly. The companies said the model would reason about chip design and verification, run the tools, interpret their output and iterate toward results that engineers then review. OpenAI will host the model and license Synopsys software for development, with a shared revenue framework. Synopsys chief executive Sassine Ghazi said its sign-off tools would still verify whether a design works.
