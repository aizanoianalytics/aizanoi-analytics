AWS open-sources a local guardrail for AI agent tool calls

Amazon Web Services published the Dogwood Local Engine under an Apache 2.0 licence, a Rust library designed to sit inside an agent's harness or gateway and return allow or deny verdicts each time the agent attempts a tool call. Policies are written in a companion Dogwood language and can carry temporal conditions, such as permitting a read only if the same user signed in within the previous hour. The engine keeps a persistent store so its decision history survives a restart.
