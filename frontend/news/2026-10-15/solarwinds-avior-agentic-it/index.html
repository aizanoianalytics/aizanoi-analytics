SolarWinds ships a goal-driven agent for enterprise IT operations

SolarWinds launched Avior, a standalone agentic system for mission-critical IT operations that pursues defined goals instead of waiting on prompts. The company says potentially disruptive actions always require explicit human approval, backed by risk-tiered autonomy, audit trails, automated rollback, data masking and least-privilege tool access. The first agent covers network engineering work such as alert correlation, configuration drift, compliance auditing and configuration backups, available from 14 October through a guided onboarding programme.
