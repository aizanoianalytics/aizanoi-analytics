Anthropic edits Claude Code to stop it rebuilding other people's games

Anthropic added two sentences to the Claude Code system prompt on Opus 5.5 telling the model to build original games and games within a genre, but not to recreate a specific existing title even when it is relabelled as original. Staff member Addy Osmani confirmed the change, saying use of Claude to infringe intellectual property breaches the company's usage policy and that projects built from a user's own designs should keep working.
