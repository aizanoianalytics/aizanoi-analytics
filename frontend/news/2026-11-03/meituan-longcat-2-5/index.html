Meituan ships a 1.6-trillion-parameter agent model without the weights

LongCat-2.5 is live on Meituan's API platform, keeping the 1.6-trillion-parameter mixture-of-experts shape of LongCat-2.0 with roughly 48 billion parameters active per token. The pitch has moved from writing code to finishing projects: native image and video input, long-horizon reinforcement learning built from real agent failures, and support for Claude Code, Codex and other harnesses. Pricing is $0.30 per million input tokens and $1.20 per million output; no open-weight release has been announced.
