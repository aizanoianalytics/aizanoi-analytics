Microsoft says ARTEX agents now carry attackers from a GitHub search to Key Vault in minutes

Microsoft Threat Intelligence has published an analysis of ARTEX, an open-source framework that coordinates language-model agents through reconnaissance, exploitation and reporting with little human involvement. Since July, Microsoft says Salt Typhoon, Onyx Sleet, Pearl Sleet, Crystal Typhoon and financially motivated groups have adopted it. In one Storm-0940 campaign it recorded more than 151,000 failed sign-ins, peaking at 2,900 a minute; in another an agent moved from finding client secrets on GitHub to reading Azure Key Vault in five minutes.
