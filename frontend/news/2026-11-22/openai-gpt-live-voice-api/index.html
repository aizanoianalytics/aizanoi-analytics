OpenAI puts its full-duplex voice model into the developer API

OpenAI added GPT-Live-1.1, its full-duplex voice model, to the Live API on 19 November, improving pronunciation, accent consistency and transcription across languages. Developers can reuse an existing Live session configuration, and a new standby option pauses inference after 5–60 seconds of silence and resumes when someone speaks. The model has powered ChatGPT’s voice mode since October, when OpenAI began retiring its older Advanced and Standard voices.
