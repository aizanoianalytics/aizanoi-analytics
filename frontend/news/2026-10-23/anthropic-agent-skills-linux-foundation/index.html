Anthropic hands its Agent Skills standard to the Linux Foundation

Anthropic donated Agent Skills, the folder-and-SKILL.md convention that gives agents procedural knowledge, to the Agentic AI Foundation, the Linux Foundation body it co-founded with Block and OpenAI and to which it already donated the Model Context Protocol. Anthropic says more than 70 platforms including ChatGPT, Cursor, GitHub Copilot and VS Code have adopted the standard it published in December 2025, with a million skills published and nearly 280 million installs.
