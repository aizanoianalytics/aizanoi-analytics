Microsoft recasts Copilot as the operating system for work

Satya Nadella opened Ignite in San Francisco by describing Copilot as "the new operating system for work". Word, Excel and PowerPoint are now generally available inside Copilot, alongside shared Workspaces, a Code surface and an Autopilot agent that runs tasks continuously; billing for Autopilot will use Copilot Credits, with pricing still unannounced. Microsoft also published Code 2 and Cyber 2 models, brought GPT-6.2 and Meta's latest models into Foundry, and said 50 million agents are managed through Agent 365.
