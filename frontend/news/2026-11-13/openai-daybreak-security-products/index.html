OpenAI turns frontier cyber work into two security products

OpenAI launched two security products at its Cyber at the Frontier keynote: Daybreak Red Team, in early access, which runs agent teams against web applications to confirm vulnerabilities and test patches, and Daybreak Defense Factory, which traces findings through a codebase and drafts fixes for engineers to approve. Both run on OpenAI's cyber models, currently GPT-6 Cyber, with customer-set scope and isolated test environments.
