VS Code 1.146 starts countdown on its Local agent harness

Microsoft's VS Code 1.146 adds an experimental Inbox view for tracking agent sessions, chat windows and side-by-side model comparisons, and starts a three-month countdown on the Local agent harness. The Local harness will be removed in February 2027 and is frozen in the meantime, with Microsoft directing users to the Copilot harness, which also enforces managed sandbox and permission policies that the older runtime lacks.
