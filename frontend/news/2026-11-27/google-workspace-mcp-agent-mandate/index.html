Google sets February 2027 deadline for AI agents to reach Workspace through MCP

Google made its Workspace MCP servers and command-line interface generally available and set 1 February 2027 as the date AI agents must use them instead of Workspace REST APIs. The gateways cover Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks, with Keep planned, and check every request against permissions, data-loss rules and classification labels. Agents need dedicated OAuth client IDs and user confirmation before sending external email, changing Drive sharing or making bulk edits. Quota billing starts 1 April 2027.
