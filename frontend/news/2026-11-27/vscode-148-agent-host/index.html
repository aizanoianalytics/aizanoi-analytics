VS Code 1.148 makes Agent Host chat 30% faster and keeps machines awake for agents

Visual Studio Code 1.148 speeds up Agent Host chat, with responses beginning about 30% sooner than the previous Stable release and within roughly 5% of the older harness, Microsoft said. A preview setting can keep a machine awake while an agent works, including after the window closes. The release adds worktree cleanup for remote agent hosts, per-host sandbox profiles and one-click Ubuntu Dev Containers for isolated agent sessions. Microsoft also repeated that the Local harness is deprecated and will be removed in February 2027.
