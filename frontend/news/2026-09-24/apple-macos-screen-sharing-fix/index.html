Apple ships out-of-band macOS patch for Screen Sharing authentication bypass on the same network

Apple on Thursday released macOS Tahoe 26.6.1, macOS Sequoia 15.7.9 and macOS Sonoma 14.8.9 in an out-of-band update closing CVE-2026-65400, a Screen Sharing authentication flaw allowing attackers on the same network to log in without valid credentials. The advisory credits researcher Alfredo Pesoli through Bynario Atlas and says the bug was fixed with improved state management. Depending on Screen Sharing settings, an attacker could view the screen, open apps or take other actions. Apple did not confirm exploitation in the wild.
