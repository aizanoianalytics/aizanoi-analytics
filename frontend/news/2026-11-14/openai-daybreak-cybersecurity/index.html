OpenAI moves into cybersecurity with Daybreak attack and patch agents

OpenAI has launched two security products under its Daybreak brand, both running on a model it calls GPT-6 Cyber. Daybreak Red Team, in early access, uses agents to read an application's source and context, map attack paths, check findings from bug bounty reports or scanners and test patches. Daybreak Defense Factory takes the defensive side, scanning a codebase and opening pull requests with fixes and tests for developers to approve.
