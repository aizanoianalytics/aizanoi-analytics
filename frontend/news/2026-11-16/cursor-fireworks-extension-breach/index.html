A stolen Fireworks key let attackers ship a malicious Claude Code extension

Cursor says attackers used an access key stored at inference provider Fireworks AI to copy historical coding-agent traces, some containing unredacted credentials, and then distributed malicious builds of Anthropic's Claude Code extension through Cursor's marketplace on 29 October. Up to 5,000 developers were exposed to malware that installed persistent SSH backdoors. Cursor says fewer than 0.05% of users had traces exposed and fewer than 0.01% had credentials compromised.
