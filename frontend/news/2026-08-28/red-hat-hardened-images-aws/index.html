Red Hat Hardened Images gain AWS Inspector and ECR scanning, OTel 2.0 telco AI lands

Red Hat's Friday Five notes that AWS InspectorScan API and ECR Basic scanning now support Red Hat Hardened Images, giving container security teams vulnerability alerts and supply-chain verification against the same images they already pull. Separately, Red Hat, AT&T, AMD, Dell, Microsoft and GSMA released OTel 2.0, a domain-specific AI model for telecommunications built on the open-source SDG Hub to convert technical standards into synthetic training data.
