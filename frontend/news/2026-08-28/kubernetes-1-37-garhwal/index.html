Kubernetes 1.37 "Garhwal" ships with metrics API graduating after nine years in beta

The Cloud Native Computing Foundation released Kubernetes 1.37, codenamed Garhwal, with 67 enhancements across stable, beta and alpha maturity. Headline changes include the metrics.k8s.io API graduating to general availability after nearly nine years in beta, KYAML output for kubectl reaching stable, and dynamic resource allocation gaining device taints, tolerations and a NUMA-aware attribute so schedulers can place GPU and accelerator workloads without bespoke device plugins.
