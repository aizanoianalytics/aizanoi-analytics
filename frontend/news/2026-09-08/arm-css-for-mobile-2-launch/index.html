Arm launches CSS for Mobile 2 with neural GPU and on-device AI cluster

Arm announced its CSS for Mobile 2 platform on September 8, combining the new Mali G2-Ultra NX GPU with a C2 CPU cluster and SME2 acceleration tuned for agentic on-device AI and neural graphics. The Mali G2-Ultra NX is the first Mali GPU with dedicated neural accelerators wired into the graphics pipeline, alongside a third-generation ray tracing unit. Arm framed the launch as the foundation for an 'agentic era' spanning cloud, edge and physical AI.
