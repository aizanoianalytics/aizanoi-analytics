Google sets a two-stage shutdown for its Jules coding agent

Google will retire Jules, its asynchronous coding agent, on 31 December: sessions can be finished until 11 November, after which the product turns read-only. Google says lessons from Jules are being folded into Antigravity, the agent-first platform it launched with Gemini 3. Export covers account settings, environment variables, scheduled tasks, connected repositories, memories, setup scripts and session logs, but there is no automatic migration and code already on GitHub is unaffected.
