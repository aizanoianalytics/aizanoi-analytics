Agents started more than 40% of GitHub pull requests in September

GitHub's Octoverse report puts agent-started pull requests above 40% in September, up from 17% in March, or about 110 million in the month alone. Developers made 34.3 billion commits and merged 1.3 billion pull requests in the year to 30 September, and 55% of Copilot's monthly active users now use agentic features. Repositories created this year with an agent configuration file averaged eight times the commits of those without one.
