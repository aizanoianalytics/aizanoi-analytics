DeepSeek publishes a coding agent built to need less supervision

DeepSeek's Harness team released dsh-superagent on GitHub under the MIT licence, a research prototype in which a resident Router hands requests from an authorised person to isolated Worker sessions that reply in the original thread, often with a pull request. It listens to GitHub events and optionally Feishu, opens a work item per request and shows a panel of items that need a human. DeepSeek calls it research code rather than an official product, and says parts of its design write-up are not implemented.
