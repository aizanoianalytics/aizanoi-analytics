Windows Server 2028 preview ships hardened by default and asks admins to keep up

Microsoft used Ignite to open the Windows Server 2028 public preview, whose Server Core install arrives with hundreds of security settings already on: Kerberos ahead of NTLM, extra protections around LSASS, modern-only TLS ciphers, hybrid post-quantum key exchange built on ML-KEM and restricted remote desktop defaults. Microsoft says the baseline follows DISA STIG guidance, and administrators can still re-enable features. The cost is compatibility with legacy protocols and older management tools, and the hardening applies to new installations only.
