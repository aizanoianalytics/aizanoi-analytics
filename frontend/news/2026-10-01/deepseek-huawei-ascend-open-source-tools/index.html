DeepSeek open-sources a programming stack for Huawei's Ascend chips

DeepSeek released open-source software built with Huawei to program the company's Ascend AI accelerators, led by an Ascend version of TileLang, the programming language it has used for about a year. Six modules mirror the tooling DeepSeek already published for Nvidia hardware, including DeepGEMM for matrix mathematics and DeepEP for large-scale communication between chips, and the two companies also optimised a supernode of 128 Ascend 950 processors. Huawei said it fully supported the work, which aims at an independent software ecosystem beyond Nvidia's CUDA.
