Nvidia ships an open agent safety stack with more than 100 partners

Nvidia released the Open Agent Safety Platform, pairing two components with different jobs. OpenShell is an Apache 2.0 runtime that sandboxes agent fleets with kernel-level isolation and enforces a declarative policy over the files, networks, tools and credentials each may reach. Sentry is a monitoring design that runs on BlueField-4 data processing units off the agent's own compute, so it can quarantine a runaway workload in milliseconds. Nvidia says the stack, built with more than 100 organisations including Anthropic and Microsoft, could have stopped this summer's Hugging Face breach.
