Synology launches ActiveProtect Manager 2.0 with cross-platform recovery and a path to AI-driven threat mitigation

Synology released ActiveProtect Manager 2.0 on Thursday, the latest software update for its ActiveProtect data protection appliances, expanding platform coverage and introducing cross-platform recovery alongside future AI-driven threat mitigation. The release adds Auto Fallback, which restores the latest clean backup if integrated third-party antivirus engines such as Microsoft Defender, Bitdefender or ESET flag malware in a recent snapshot. ActiveProtect Manager 2.0 is available at no additional cost for all DP-Series appliances, with AI-driven capabilities to follow in later updates.
