Beijing drafts export licences for its most capable cyber models

China's commerce and science ministries published Announcement No. 48 on 16 October, proposing to add 40 technologies to the export-control catalogue, 23 of them in artificial intelligence. Systems that generate or mutate malicious code above set success rates would be banned outright, while AI-assisted vulnerability discovery, very large model weights and high-capability agents would be restricted. Remote API access and already published open-source work are excluded, and a registration duty applies while comments run to 15 November.
