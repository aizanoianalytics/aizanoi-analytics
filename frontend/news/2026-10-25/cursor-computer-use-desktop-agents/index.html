Cursor lets its coding agent click around your desktop

Cursor said on 23 October that its agents can now click and type across applications on a developer's own machine, not just a browser, and can drive the iOS Simulator to test a feature they have just written. The tool runs automatically when a task needs it or when a developer mentions Computer Use in a prompt. Cursor has not published the permission model, the supported systems or benchmark results for the local version.
