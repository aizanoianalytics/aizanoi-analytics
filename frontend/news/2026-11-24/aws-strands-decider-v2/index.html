AWS ships five open decision models that score options instead of writing text

Strands Agents, the AWS-backed open-source project, released Strands Decider v2: five Gemma 4-based models from 2 billion to 31 billion parameters that return a probability for each option an agent supplies, in a single forward pass. The models were trained on 17.5 million decision examples, support up to 255 options, and ship under Apache 2.0 on Hugging Face. AWS also launched Box CLI, which runs coding agents such as Claude Code and Codex inside a sandbox with controlled access.
