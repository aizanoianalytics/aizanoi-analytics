NVIDIA and Oracle take Vera Rubin to multi-gigawatt scale on OCI

NVIDIA and Oracle said OCI will scale Vera Rubin NVL72 systems into multi-gigawatt Superclusters and that Vera CPUs are now generally available on the cloud. The pitch splits work between GPUs for training and inference and Arm-based CPUs for the tool calls, code tests and retrieval agents perform between model calls, so customers can size each side separately. Oracle also plans HGX Rubin NVL8 systems and is stacking Intel, AMD, Google TPU and Cerebras silicon onto the same platform.
