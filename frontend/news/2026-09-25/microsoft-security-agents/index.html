Microsoft highlights new controls for AI agents in security stack

Microsoft’s September security update highlights changes across Defender, compliance and endpoint management as AI agents increasingly operate inside employee workflows. The company presents agent identity, oversight and data-protection controls as part of the security boundary rather than as a separate AI feature layer.
