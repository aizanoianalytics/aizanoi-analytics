Microsoft declares a Code Red over the twelve-hour collapse of Exchange Online

Microsoft has declared a Code Red across Microsoft 365 after the 12-13 November outage, the internal memos reviewed by Reuters show. M365 Core president Jason Henderson called it the most customer-impacting incident in Exchange Online's history; a vice president, Amanda Silver, wrote that responders traded more than 11,000 messages across 11 Teams chats while diagnostic data stayed scattered. Microsoft's post-incident report blamed an undetected Windows scalability defect from July and a Teams failover onto infrastructure already short of capacity. It now targets one-hour worldwide resolution.
