Microsoft adds xAI Grok models as a selectable option inside Copilot, Word, Excel and PowerPoint

Microsoft on Saturday began rolling out xAI's Grok models as a user-selectable option inside Copilot and dedicated add-ins for Word, Excel, and PowerPoint, with availability opening first to Microsoft Frontier program customers. The integration, announced by Satya Nadella, extends a multi-model strategy that already includes Anthropic's Claude and lets enterprise users pick the underlying engine for tasks such as financial modeling and pitch-deck creation. Existing Grok connectors for Outlook mail, Teams, SharePoint, and OneDrive had already been live by May.
