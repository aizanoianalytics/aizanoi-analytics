Discord is replacing Electron and React Native with a Rust client

Discord is moving its desktop client off Electron and its mobile apps off React Native, rebuilding shared code in Rust on top of GPUI, chief technology officer Stanislav Vishnevskiy said. He posted an image of the Windows client idling at 290MB of memory, well below what the current Electron build can consume. Discord has used Rust in its infrastructure and voice stack since 2018. The company says it hopes to put the new client into user testing soon.
