Kuaishou's Kling Image 4.0 renders 8K and 2,000 characters of type in one frame

Kuaishou released Kling Image 4.0 on 18 November with native 8K generation and up to ten coordinated images from a single prompt. The model combines visual understanding and image generation in one architecture and is available through an API for developers and enterprise customers. Kuaishou says it can render up to 2,000 characters inside a single image across seven languages and more than 70 preset commercial fonts, and that users can supply references to steer typography, lighting and colour. The target is production work: advertising, storyboards, product pages and long-form layouts.
