Ruby2Shell turns a one-byte overflow into pre-auth RCE, and three big products still ship it

CVE-2026-132825, published as GHSA-34m4-m9fh-gqp5, is an off-by-one heap overflow in Ruby's case conversion for legacy single-byte encodings: upcasing the German sharp s writes two bytes where the loop reserves one. Veria Labs reports it is reachable without authentication in default Rails and classic Sinatra configurations; UTF-8 is not affected. Ruby fixed it on 18 November in 3.3.14, 3.4.13 and 4.0.10. As of 04:59 UTC on 20 November, GitLab, GitHub Enterprise Server and Chatwoot still bundle a vulnerable interpreter with no fixed release. No exploitation has been reported.
