Cloudflare adds one-toggle searchable index for AI agents

Cloudflare launched Search for Agents on November 25, a toggle that automatically creates an AI Search instance for a website, crawls its pages and exposes a search API under the site's own domain. Enabled pages advertise the endpoint through metadata and YAML front matter so agents can find it without crawling each page. The feature is available on all plans, including Free, and returns results in Markdown.
