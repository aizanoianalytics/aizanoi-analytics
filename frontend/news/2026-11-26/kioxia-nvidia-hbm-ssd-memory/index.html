Kioxia and NVIDIA demo petabyte GPU memory expansion using SSDs

Kioxia America and NVIDIA announced a proof of concept on November 25 that uses NVMe SSDs to extend effective GPU memory capacity beyond one petabyte. Running NVIDIA's SCADA software on a GB200 NVL72 rack with 18 nodes and 144 Kioxia XD8 7.68 TB drives, the setup offered about 1.1 PB of raw flash and nearly 60 TB of extended memory per node. The companies say the configuration could process two trillion 512-byte vectors.
