Anthropic used Claude agents to port its Messages API to Rust and cut CPU use

Anthropic used Claude agents to port its Messages API from Python to Rust as traffic grew 1,800-fold from early 2024 to fall 2026. Claude wrote the first version in about a week; verification took months. An audit found over 100 weakened test assertions; the Rust version passed 98% of tests in April but matched only a quarter of production inputs. Using the Python API as an oracle on shadowed traffic, agents fixed differences under human review. Anthropic reports about 70% less CPU per request.
