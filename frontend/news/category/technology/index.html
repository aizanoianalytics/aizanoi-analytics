CNCF graduates Kubeflow as a cloud-native AI standard

The Cloud Native Computing Foundation promoted Kubeflow from incubating to graduated status, marking it as a mature, production-ready platform for running AI and machine-learning workloads on Kubernetes. The project, originally created at Google in 2017, has accumulated more than 33,000 GitHub stars across its repositories and roughly 260 million PyPI downloads for its Python packages, with Bloomberg, NVIDIA, Red Hat, LinkedIn and Spotify among the named adopters.

Shopify CEO Lütke ships walgit, an S3-native Git server

Shopify chief executive Tobias Lütke released walgit, an open-source database-free Git server written in Rust that runs directly on top of S3-compatible object storage. The initial release on Aug. 24 supports Git's bundle-uri mechanism for distributing large repositories via object storage or CDNs, Git LFS, a built-in web interface and OIDC authentication, with no leader node and no relational database dependencies.

KubeRay 1.7 lands with a History Server and stronger security

The KubeRay project released versions 1.6 and 1.7 of its Kubernetes operator for Ray distributed workloads, adding a beta History Server that retains cluster and job logs after a RayCluster is deleted. The 1.7 release also brings native Kubernetes NetworkPolicy support, automated mTLS via cert-manager, RayCronJob scheduling and an embedded RocksDB backend that removes the external Redis dependency for GCS fault tolerance.
