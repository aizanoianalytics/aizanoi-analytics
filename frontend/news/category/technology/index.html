The Cloud Native Computing Foundation released Kubernetes 1.37, codenamed Garhwal, with 67 enhancements across stable, beta and alpha maturity. CNCF blog reframes Kubernetes as five pieces of scaffolding, not a body of APIs

CNCF published a primer for IT generalists moving off VMware, arguing that Kubernetes is best learned through five pieces of scaffolding — desired state and reconciliation, the disposable machine, the four networking layers, storage as a plugin, and policy as a later choice — instead of trying to absorb the whole API surface at once. The post lands alongside Kubernetes 1.37 and the 1.36 release of mid-August, both of which tighten the default control plane.

Shopify CEO Lütke ships walgit, an S3-native Git server

Shopify chief executive Tobias Lütke released walgit, an open-source database-free Git server written in Rust that runs directly on top of S3-compatible object storage. The initial release on Aug. 24 supports Git's bundle-uri mechanism for distributing large repositories via object storage or CDNs, Git LFS, a built-in web interface and OIDC authentication, with no leader node and no relational database dependencies.
