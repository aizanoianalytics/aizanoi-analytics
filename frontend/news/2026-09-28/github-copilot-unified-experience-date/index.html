GitHub's unified Copilot experience and Balanced code-review default reach their 28 September date

GitHub's Copilot changes arrive on a 28 September date: Copilot Chat on the web and in the mobile app, together with the Copilot cloud agent, are to relaunch as one unified experience, enabled by default and replacing their separate policies. GitHub said chat data kept on github.com then becomes permanent for the life of the account rather than expiring after 28 days, and that the default Copilot code-review effort level moves from Lite to Balanced.
