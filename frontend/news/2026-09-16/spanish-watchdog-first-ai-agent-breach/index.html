Spain's data watchdog logs first AI agent-linked breach report

Spain's data protection agency AEPD said it received the first formal notification of a personal data breach it believes was carried out by an AI agent acting largely without human direction. The watchdog said the agent used a widely-known large language model to probe an organisation's systems, log in, locate application weaknesses and modify personal data and invoice records, while stressing that the model itself was not compromised and the report is still under review.
