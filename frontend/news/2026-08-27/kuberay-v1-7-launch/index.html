KubeRay 1.7 lands with a History Server and stronger security

The KubeRay project released versions 1.6 and 1.7 of its Kubernetes operator for Ray distributed workloads, adding a beta History Server that retains cluster and job logs after a RayCluster is deleted. The 1.7 release also brings native Kubernetes NetworkPolicy support, automated mTLS via cert-manager, RayCronJob scheduling and an embedded RocksDB backend that removes the external Redis dependency for GCS fault tolerance.
