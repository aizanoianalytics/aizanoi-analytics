Shopify CEO Lütke ships walgit, an S3-native Git server

Shopify chief executive Tobias Lütke released walgit, an open-source database-free Git server written in Rust that runs directly on top of S3-compatible object storage. The initial release on Aug. 24 supports Git's bundle-uri mechanism for distributing large repositories via object storage or CDNs, Git LFS, a built-in web interface and OIDC authentication, with no leader node and no relational database dependencies.
