Privacy · Browser-local by design

What stays on your device

Aizanoi Analytics is a static-first website. AizanoiOS does not require a public account or upload your Workspace to an Aizanoi application backend. Some features intentionally store data inside your browser, while ordinary website and external-network requests still have normal network privacy boundaries.

Workspace files

Workspace uses this site’s browser storage (IndexedDB). Files created or imported through Workspace, Notepad, Web Editor, Camera and compatible local media flows can include real Blob contents, not only filenames. They stay associated with this browser profile and this site origin unless you explicitly download or export them.

Workspace includes a versioned backup/export and restore flow. The Protect storage action can ask the browser for persistent storage, but persistent storage is not a backup and does not guarantee that data survives profile deletion, browser reset or manual site-data clearing.

Camera

Camera permission is requested only after you choose Start camera. The current photo flow requests video/camera access only; it does not request microphone access. A captured photo is written to Workspace · Photos in IndexedDB. Camera and preview media tracks are stopped when the app closes.

Local preferences and small records

Some small state is stored in localStorage instead of Workspace. Examples include AizanoiOS shell/window preferences, Arcade scores, Historical Worlds session/location state and local dashboard settings. These records remain browser-local unless a feature explicitly gives you an export or external-navigation action.

Browser app and external links

The AizanoiOS Browser does not use an Aizanoi proxy. A destination is requested directly by your browser. Embedded destinations run inside a restricted iframe and some sites refuse embedding, in which case you can open them externally. When you visit an external website, that site and its infrastructure apply their own privacy practices and can receive the network information normally sent by your browser.

Website requests and server logs

Loading Aizanoi Analytics necessarily sends normal web requests to the hosting/network infrastructure serving the site. Those requests can expose ordinary connection metadata such as an IP address, request time, requested path, user agent and related HTTP metadata to infrastructure involved in delivering the site.

The public repository does not define a production access-log retention period, so this page does not claim a specific retention duration. The application source currently contains no third-party visitor analytics/tracking integration identified by the project’s repository audit.

News, media and dashboard links

News source links, research citations, videos, Web Editor resources and other external URLs can take you to third-party services. Aizanoi Analytics cannot control what those services collect. Generated HR Analytics public products use committed synthetic data; local dashboard preferences can still be stored in your browser.

Deleting browser-local data

You can remove Aizanoi browser-local data by clearing site data for aizanoianalytics.com in your browser or by deleting the relevant browser profile. Do that only after exporting any Workspace files you want to keep. Clearing site data can remove IndexedDB files, localStorage settings and other origin-scoped browser storage.

No hidden cloud sync promise

There is currently no public Aizanoi account system that synchronizes AizanoiOS Workspace files between devices. A file visible on one browser should not be expected to appear automatically on another device. If cross-device sync is introduced later, it requires an explicit product and privacy decision rather than silently changing this local-first boundary.
