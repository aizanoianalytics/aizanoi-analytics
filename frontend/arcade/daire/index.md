# Ev

Walkable apartment at `/arcade/daire/`. Built from the owner's sketch and room notes, not from the factory.

Room 4 was not described, so that volume is empty and labeled. Rooms 1, 2, 3, 5, 6, 7, 8 and 9 use the stated furniture. The plan reading is a reconstruction: the sketch had no numbers, so doors are labeled in the HUD by zone.

The page reuses the already vendored Three.js r180 runtime at `/arcade/factory/engine.js`. It does not copy that bundle.
