Tableau Extensions

Aizanoi Hello is a connectivity pilot for Tableau Dashboard Extensions. It proves that a web application published by Aizanoi Analytics loads, initializes and can be added from Tableau Desktop. It reads no dashboard, worksheet or data source information.

Open pilot app Download .trex manifest

How to Install

  1. In Tableau Desktop, create or open a dashboard.
  2. Drag Extension from the Objects panel onto the dashboard.
  3. Choose Access Local Extensions and select the downloaded aizanoi-hello.trex file.
  4. Approve the extension dialog. The pilot shows Tableau connected when the handshake succeeds.

On a plain browser the same URL shows Demo / Tableau not detected — that state is expected outside Tableau.

Requirements

  • Tableau Desktop 2018.2 or newer (dashboard extensions; verified against 2023.1).
  • Tableau Server 2018.2 or Tableau Cloud.
  • Network access to https://aizanoianalytics.com from the machine running Tableau.
  • A modern Chromium-based browser engine (the Tableau embedded browser).

Privacy & Security

  • No data access — the pilot requests no permissions and reads no dashboard, worksheet or data source content.
  • No telemetry — the extension makes no analytics, tracking or error-reporting calls.
  • No third-party requests — all assets (HTML, CSS, JS, the pinned Extensions API library) load from this origin only.
  • No credentials — the extension stores and transmits nothing.
  • Only dummy/demo content is used; no real corporate data is read, copied, stored or sent.

Known risk of hosted extensions

A dashboard extension is a web page that runs inside Tableau. Once loaded, any future change to the public JavaScript could alter what an extension can do inside your Tableau session. This pilot minimizes that exposure by requesting no permissions at all, so it cannot read data even if its code changed. Future Aizanoi extensions that need workbook data will ship with a separate permission model, pinned versions and a security review before publication.

Not a validated deployment yet

This pilot has not yet been validated on a corporate Tableau Desktop 2023.1 machine. Corporate proxy, TLS inspection or extension policy may still block it; those limits will be documented rather than bypassed.
