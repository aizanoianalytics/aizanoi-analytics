# Istanbul Airport

An original, source-led interactive interpretation of Istanbul Airport’s passenger journey.

This experience deliberately does **not** reproduce architectural drawings, brand assets or copyrighted imagery. Geometry, rhythm and movement are derived from public architecture references and official passenger guides:

- `nordicarch.com/projects/istanbul-airport`
- `istairport.com` passenger guides and map pages

The renderer uses the shared Aizanoi flat-blocky world runtime, but the architecture and spatial story are airport-specific rather than historical-city reuse.
