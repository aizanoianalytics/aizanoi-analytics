# Ancient Cities

Standalone, source-led historical city environments.

- [`rome-410-476/`](rome-410-476/) — Late Antique Rome from the sack of 410 through 476. Includes the Vatican / Old St. Peter’s, Aurelian Walls, source ledger, user-selected ambient audio, schematic modern overlay and a 14-region minimap.

These pages deliberately use no CDN assets, runtime map tiles or tracking. Read the city-specific `AGENTS.md` before changing the renderer or historical dataset.
