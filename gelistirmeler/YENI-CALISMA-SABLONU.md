# Yeni Çalışma Şablonu

Bu dosyayı kopyalayıp `gelistirmeler/YYYY-MM-DD-kisa-ad/NOTLAR.md` olarak aç, köşeli alanları doldur.

```markdown
# [Çalışma adı] — NOTLAR

- Tarih: [YYYY-MM-DD]
- Durum: [plan / sürüyor / bitti]
- İlgili alan: [örn. frontend/, scripts/news/, sadece-yerel...]

## Amaç (1-3 cümle)

[Ne, neden?]

## Kapsam dışı

[Neye dokunulmayacak?]

## Plan

1. [adım]
2. [adım]

## Durum günlüğü

- [YYYY-MM-DD] [ne yapıldı, sonuç]

## Doğrulama

- [çalıştırılan komut + sonuç]
```
