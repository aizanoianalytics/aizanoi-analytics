# Infrastructure examples

These are sanitized reference configurations for deployment. Production nginx/systemd files and credentials are maintained on the server and are not copied from this directory automatically.

- `nginx/aizanoianalytics.com.conf.example` — static frontend, `/historic-world/` exact route, and `/api/` proxy shape
- `systemd/aizanoi-backend.service.example` — backend service shape; verify the real Node path before use
